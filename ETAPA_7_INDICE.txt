🔐 SEGURANÇA IMPLEMENTADA
═══════════════════════════════════════════════════════════════════

✅ Autenticação:
   • JWT com expiração (7 dias)
   • Senhas com bcrypt (10 rounds, inquebrável)
   • Refresh token endpoint (renovar sem re-login)

✅ Autorização:
   • Role-based: admin, manager, staff, caixa
   • Isolamento multi-tenant: (email, tenantId) único
   • Middlewares de permissão (admin, financial, stock)

✅ Proteção de Dados:
   • req.user + req.tenant injetados pelo middleware
   • Todas queries filtram por tenantId
   • Password nunca exposto em responses

✅ Stateless:
   • Nenhum token armazenado no servidor
   • Redimensionável horizontalmente
   • Não precisa de session store

🚀 COMO EXECUTAR
═══════════════════════════════════════════════════════════════════

1. Instalar Dependências:
   ```bash
   cd backend
   npm install
   cd ../frontend
   npm install recharts
   ```

2. Configurar .env:
   ```bash
   # backend/.env
   DATABASE_URL="postgresql://postgres:password@localhost:5432/delivery_erp"
   JWT_SECRET="your-secret-key-change-in-production"
   PORT=3001
   ```

3. Sincronizar BD:
   ```bash
   cd backend
   npx prisma generate
   npx prisma db push
   ```

4. Iniciar Backend:
   ```bash
   cd backend
   npm run dev
   # Backend rodando: http://localhost:3001
   ```

5. Iniciar Frontend:
   ```bash
   cd frontend
   npm run dev
   # Frontend rodando: http://localhost:5173
   ```

6. Login (criar usuário primeiro):
   Email: admin@empresa.com
   Senha: admin123
   Empresa: (selecione na lista)

🔄 FLUXO DE DADOS
═══════════════════════════════════════════════════════════════════

1. LOGIN
   LoginPage (form)
   ↓
   POST /api/auth/login
   ↓
   authController.login
   ├─ find User (email, tenantId)
   ├─ compare password
   ├─ jwt.sign()
   ↓
   { token, user }
   ↓
   localStorage + axios header
   ↓
   DashboardCharts

2. DADOS GRÁFICOS
   useEffect DashboardCharts
   ├─ Loop 12 meses
   ├─ GET /api/financial/dre?month=M&year=Y
   ├─ GET /api/financial/kpis?period=month
   ↓
   middleware authenticate
   ├─ jwt.verify(token)
   ├─ req.user = decoded
   ├─ req.tenant = { id: tenantId }
   ↓
   financialRoutes handler
   ├─ prisma.order.findMany({ where: { tenantId } })
   ├─ calcular KPIs/DRE
   ↓
   { revenue, costs, profit }
   { customers, sales }
   ↓
   Recharts renderiza

✅ TESTES RÁPIDOS

   curl http://localhost:3001/api/financial/kpis

     -H "Authorization: Bearer <token>"

📞 SUPORTE
═══════════════════════════════════════════════════════════════════

Erro: "CORS error preflight"
→ Adicionar CORS em backend index.ts
→ app.use(cors({ origin: 'http://localhost:5173' }))

Erro: "Token inválido"
→ localStorage.clear()
→ Fazer login novamente

Erro: "Charts vazios"
→ Verificar /api/financial/dre retorna dados
→ Confirmar month/year formato
→ Check tenantId injetado corretamente

Erro: "Database migration failed"
→ npx prisma db push --force-reset
→ Cuidado: deleta todos os dados!
