🔧 COMO USAR:

PRIMEIRA VEZ (com Admin):
  1. Clique direito em "iniciar_sistema.bat"
  2. Selecione "Executar como Administrador"
  3. Clique "Sim" na confirmação Windows
  4. Aguarde até as 2 janelas (Backend + Frontend) abrirem

PRÓXIMAS VEZES (normal):
  → Duplo clique direto em "iniciar_sistema.bat"
  → O sistema inicia automaticamente
  → PostgreSQL deve estar rodando antes

🐛 TROUBLESHOOTING RÁPIDO:

Erro: "Acesso Negado"
  └─ Execute como Administrador (direito do mouse)

Erro: "PostgreSQL não está rodando"
  └─ Inicie PostgreSQL (Services ou linha de comando)

Erro: "npm not found"
  └─ Reinstale Node.js, adicione ao PATH

Erro: "Prisma migration failed"
  └─ Execute no terminal: npx prisma db push --force-reset
