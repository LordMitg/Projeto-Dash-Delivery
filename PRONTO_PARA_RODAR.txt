PRÉ-REQUISITOS (Verificar Antes)
════════════════════════════════════════════════════════════════════

✓ PostgreSQL 12+ instalado e RODANDO
  → Services do Windows → PostgreSQL → Start

✓ Node.js 18+ instalado
  → Abra CMD: node --version
  → Deve retornar v18.0.0 ou superior

✓ npm 9+ instalado
  → Abra CMD: npm --version
  → Deve retornar 9.0.0 ou superior

✓ Arquivo backend/.env configurado
  DATABASE_URL="postgresql://postgres:password@localhost:5432/delivery_erp"
  JWT_SECRET="seu-valor-secreto-aleatorio"
  PORT=3001

SE FALTA ALGO:
  → Instale Node.js (npm vem junto): https://nodejs.org
  → Instale PostgreSQL: https://www.postgresql.org/download/windows/
  → Crie arquivo .env copiando .env.example

════════════════════════════════════════════════════════════════════
SE NÃO FUNCIONAR
════════════════════════════════════════════════════════════════════

Erro 1: "Acesso Negado"
  → Execute como Admin (direito do mouse)

Erro 2: "PostgreSQL não conecta"
  → Verifique se PostgreSQL está rodando
  → Services → PostgreSQL → Status = Started

Erro 3: "Port 3001 já em uso"
  → Feche outra janela do terminal
  → Ou mude PORT no .env para 3002

Erro 4: "Recharts não funciona"
  → npm install recharts (no frontend)

Erro 5: "Login falha"
  → Verifique se .env tem DATABASE_URL correto
  → Execute: psql -U postgres -d delivery_erp -f backend/scripts/seed-test-user.sql

Erro 6: "npm install lento"
  → Isso é normal (primeira vez)
  → Aguarde (não feche terminal)

MAIS AJUDA: Veja GUIA_FINAL_INTEGRACAO.md (troubleshooting completo)
